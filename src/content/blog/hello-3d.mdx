## 🧊 模型不是图片，是可以「拿起来玩」的

整个网站最重要的一件事：**看到 3D 模型，请出手摸它。**

它不是一张图，是真的立体模型，你可以：

- 🖱️ **按住左键拖动**：模型跟着你转，想看屁屁就看屁屁
- 🌀 **滚滚轮**：靠近一点看细节，或退远一点看全貌
- ✋ **按住右键拖动**：把模型平移到旁边（它不会生气）
- 📱 **手机的话**：一指转、两指捏合缩放，跟看地图一样

不信？下面这只就是活的，现在就转转看：

有些模型会自己慢慢旋转展示（像旋转寿司），你一摸它就会停下来，
乖乖让你控制。去[模型展示间](/gallery-3d)可以看到所有住户，
点「拿起来玩」就能进到单独的房间慢慢欣赏。

## 🖍️ 画画的墙：点开有惊喜

[画画的墙](/gallery-2d)上贴满了涂鸦。逛墙的姿势：

1. **点任何一张画**，它会放大跳出来（本人比缩略图好看）
2. 放大之后，**键盘的 ← →** 可以直接翻上一张、下一张，跟翻相册一样
3. 看够了按 **Esc**，或点旁边的粉红 ✕，画就乖乖回到墙上
4. 墙的上面有一排**糖果色小标签**，点下去墙会只留下那一类的画

小彩蛋：放大看某张画的时候，浏览器的网址会跟着变。
把那个网址丢给朋友，他点开就直接看到同一张画，不用自己找 ✨

## ✏️ 博客：碎碎念集中营

你现在就在这里！文章会记录画图和捏模型的过程、踩过的坑，
还有一些没营养但很快乐的日常。

- 文章上的 **#标签** 可以点，点了就能看到同类文章

  密语通常只告诉特定的人，如果你有拿到，输入就能解锁；
  没拿到的话⋯⋯嘿嘿，猜也没用，它是真的加密 🔐

## 🛠️ 想自己发内容？用「可爱编辑器」就好

重点来了：这个网站**不需要懂任何代码、任何语法**就能更新。
写文章、贴画、上传 3D 模型，全部用一个桌面小软件搞定，
它叫 **CuteEditor（可爱编辑器）**，长得也很可爱。

### 怎么打开

1. 找到 `CuteEditor.zip`（在电脑桌面上），右键**解压缩**
2. 双击里面的 **CuteEditor.exe**
3. 如果 Windows 跳出蓝色警告说「无法识别的应用」：
   点「**其他信息**」再点「**仍要运行**」就好。
   这是自制的小工具，没花钱买数字签名，不是病毒啦 🐭

### 第一次使用：登录

编辑器会显示一组代码，并自动打开浏览器的 GitHub 页面。
把代码输进去、点授权，就登录完成了。以后打开都不用再登。

### ✏️ 写文章（完全不用学语法！）

点上面的「✏️ 写文章」：

- **像在备忘录里打字一样**写就行：标题、一句话介绍、正文。
  加粗、列表这些都有按钮可以点，不用背任何符号
- **图片**：直接拖进编辑框，它会自动帮你压缩
- **想放一只 3D 模型在文章里**？点「插入 3D 模型」按钮选文件就好，
  编辑器会显示成一个小标签，发布后就变成可以转的模型
- **想写只给特定人看的悄悄话**？勾选「私密文章」、设一个通关密语，
  网站上就只有知道密语的人能解锁（连文件本身都是加密的）
- 写完按「🚀 发布」，等 1～2 分钟（编辑器会一直等到网站更新好，
  然后告诉你「上线了！」），点按钮就能看到成品

### 🖍️ 贴画画

点「🖍️ 贴画画」：选一张图 → 取个名字 → 按「🚀 贴上墙！」。
就这三步，图片会自动压缩，画会出现在[画画的墙](/gallery-2d)上。
「标签」和「一句话介绍」想填再填；勾「⭐ 设为精选」的话，
首页的「画画的」门会优先展示这张。

### 🧊 上传 3D 模型

点「🧊 加模型」：选一个 `.glb` 文件，编辑器会**自动压缩**它、
**自动做一张会旋转的缩略图**，你只要取名字、选一个灯光气氛，
按发布就好。模型会出现在[模型展示间](/gallery-3d)。

### 📚 后悔药

「📚 管理」页能看到所有发布过的东西：

- 打错字了？点「✏️ 编辑」改完再存
- 不想要了？点「🗑️ 删除」
- 删错了？！打开「回收桶」，按「↩️ 还原」就回来了，什么都不会丢
