## ✏️ 一、怎麼發一篇新文章?

把每一篇文章想成一個「檔案」。發文 = 新增一個檔案,就這麼簡單!

**步驟 1.** 到 `src/content/blog/` 這個資料夾,新增一個檔案,名字用英文隨便取,結尾加 `.md`,例如 `my-first-day.md`。

> 小提醒:檔名會變成文章網址,所以用英文、不要空格(多個字用 `-` 連起來,像 `my-cat`)。

**步驟 2.** 在檔案「最上面」貼一張「文章資料卡」,長這樣(照抄改字就好):

```
---
title: "我的第一天"
description: "今天捏了一隻好可愛的貓咪!"
pubDate: 2026-06-05
tags: ["日常", "貓咪"]
---
```

這張卡片在說什麼呢?
- **title** ＝ 文章標題(會變成最上面的大字)
- **description** ＝ 一句話簡介(會出現在文章列表)
- **pubDate** ＝ 日期,格式是「年-月-日」
- **tags** ＝ 標籤,像貼貼紙一樣,想貼幾個都行

**步驟 3.** 資料卡「下面」就開始打字寫內容啦,跟平常打字一樣!想要標題、粗體,看最後的「排版小抄」。

**步驟 4.** 存檔 → 上傳(這步電腦會幫你),文章就自動出現在網站上了 ✨

## 🐤 二、怎麼放會動的 3D 模型?

只要三個小動作:

**① 把檔名結尾從 `.md` 改成 `.mdx`**
（多一個 `x`,就解鎖放 3D 的魔法 🪄)

**② 在「資料卡的下面」貼這一行**(照抄,不用懂它):

```
import ModelViewer from '../../components/three/ModelViewer.tsx';
```

**③ 在你想放模型的地方,貼這一行**,再把 `duck.glb` 換成你的模型檔名:

```
<ModelViewer client:only="react" src={`${import.meta.env.BASE_URL}models/duck.glb`} environment="city" height={360} />
```

完成!那個位置就會出現一個可以轉、可以縮放的模型 🥳

### 那「我的模型檔」要怎麼來?

1. 把你做好的 `.glb` 模型檔丟進 `raw-models/` 資料夾。
2. 執行一個小指令 `npm run optimize`(電腦會自動幫模型「瘦身」,讓它變小、載入更快)。
3. 它就會自動跑到 `public/models/` 裡,接著用上面 **第 ③ 步** 把它放進文章就好!

> 兩個可以調的小設定:
> - `environment` ＝ 換氣氛燈光,試試看:`city`、`sunset`、`studio`、`park`、`dawn`…
> - `height` ＝ 模型框的高度,數字越大、框越高。

## 🧁 三、排版小抄(超簡單)

在內容裡這樣打字就會變花樣:

```
## 這是中標題
### 這是小標題

**這樣會變粗體**,*這樣會變斜體*

- 清單第一點
- 清單第二點

> 這是引用,適合放金句

[這是連結文字](https://example.com)
```

打出來會自動變漂亮,完全不用背指令~
